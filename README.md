# Harini Thiruvaipati — Portfolio

Static portfolio site (HTML5 + CSS3 + Bootstrap 5 + JavaScript ES6). No build step.

## Structure
- `index.html` – page content
- `assets/style.css` – styles
- `assets/script.js` – cursor, parallax, project filter + modal, Fetch API, form validation
- `assets/data/achievements.json` – achievements/certifications (edit this)
- `assets/img/avatar.svg` – profile monogram

## Deploy on GitHub Pages
1. Create a repo named `<your-username>.github.io` (or any name)
2. Upload all files (keep `index.html` at the root)
3. Repo → **Settings → Pages**
4. Source: **Deploy from a branch** → `main` / `/ (root)` → **Save**
5. Live in ~1 min at `https://<your-username>.github.io/`

## Run locally
Open `index.html` in a browser, or run `python -m http.server`.
